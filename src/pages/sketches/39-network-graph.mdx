## ネットワークグラフ

ノードとエッジで関係性を表現し、**力学モデル（Force-Directed Layout）**で自動的に見やすい配置を生成するスケッチです。グラフ理論の可視化と物理シミュレーションの両方を学べます。

### 操作方法

| 操作 | 動作 |
|------|------|
| ドラッグ | ノードを移動（周囲も追従） |
| 空白クリック | 新しいグラフを再生成 |

## Force-Directed Layout とは

ノードを物理的な粒子、エッジをバネとみなしてシミュレーションするレイアウト手法です。2 つの力のバランスで自然な配置が決まります。

### 1. 反発力（クーロン力）

全ノード間に「離れようとする力」が働きます。距離の 2 乗に反比例するため、近いノードほど強く反発します。

```js
const force = REPULSION / (dist * dist);
```

これにより、ノードが互いに重ならないよう広がります。

### 2. バネ引力（フックの法則）

エッジで接続されたノード間に「引き合う力」が働きます。バネの自然長からのズレに比例した力です。

```js
const displacement = dist - SPRING_LEN;
const force = SPRING_K * displacement;
```

- 距離が自然長より大きい → 引き合う
- 距離が自然長より小さい → 押し返す

### 力のバランス

この 2 つの力が釣り合う点にノードが落ち着きます。

| 力 | 対象 | 効果 |
|----|------|------|
| 反発力 | 全ノード間 | 重なりを防ぐ |
| バネ引力 | 接続ノード間 | 関連するノードを近くに |
| 中心引力 | 全ノード | 散らばりすぎを防止 |

## 減衰（ダンピング）

毎フレーム速度に `0.9` を掛けることで、振動を収束させます。

```js
node.vx = (node.vx + node.fx) * DAMPING;
```

減衰がないとノードが永遠に振動し続け、安定した配置になりません。

## グラフの生成

全ノードが接続されることを保証するため、まずランダムな**スパニングツリー**（全域木）を作り、その後にランダムなエッジを追加しています。

```js
// スパニングツリーで全接続を保証
const order = p.shuffle([...Array(count).keys()]);
for (let i = 1; i < order.length; i++) {
  edges.push({ a: order[i - 1], b: order[i] });
}

// 追加のランダムエッジ
const extraEdges = p.floor(p.random(count * 0.3, count * 0.8));
```

## ノードの見た目

接続数（次数）が多いノードほど大きく、色相も変化します。

```js
const radius = p.map(node.degree, 1, 6, 10, 22);
const hue = p.map(node.degree, 1, 6, 200, 330);
```

これにより、ハブとなるノードが視覚的に目立ちます。

## 試してみよう

- ノードをドラッグして離すと、力学モデルで再配置される様子を観察しましょう
- 何度か再生成して、接続の密度による配置の違いを比べましょう
- `REPULSION` を大きくするとノードがより広がり、`SPRING_LEN` を小さくすると密集します
- `DAMPING` を `0.99` にすると収束が遅くなり、揺れる動きが楽しめます
