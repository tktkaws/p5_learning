## ジェネラティブ山脈

**1D Perlin ノイズ**を複数層重ねて山脈のシルエットを生成し、**パララックス（視差）効果**で奥行き感を演出します。手前の層ほどマウスに大きく反応して動くため、自然な立体感が生まれます。

### 操作方法

| 操作 | 動作 |
|------|------|
| マウス左右移動 | パララックス（手前の山ほど大きく動く） |
| クリック | 新しいシードで山脈を再生成 |

## 仕組み

### 1. 1D ノイズで山の稜線を描く

`noise(x)` は X 座標に対して滑らかに変化する値を返します。これを Y 座標に変換して山の稜線を作ります。

```js
let h = noise(x * freq, layerOffset);
const y = baseY - h * peakHeight;
```

### 2. 複数オクターブの重ね合わせ

1 層のノイズだけでは単調な丘になるため、周波数を倍にしながら振幅を半分にしたノイズを加算します。

```js
h  = noise(nx, offset) * 1.0;    // 大きな起伏
h += noise(nx*2, offset) * 0.5;  // 中くらいの凹凸
h += noise(nx*4, offset) * 0.25; // 細かいギザギザ
```

低周波が全体のシルエットを、高周波が岩肌のディテールを担当します。

### 3. レイヤーによる奥行き表現

6 層の山脈を奥から手前へ順に描画します。各層で以下を変化させます：

| パラメータ | 奥 | 手前 |
|-----------|-----|------|
| 色 | 薄紫（空気遠近法） | 濃紺〜黒 |
| 位置 | 高い（画面上方） | 低い（画面下方） |
| ノイズ周波数 | 低い（なだらか） | 高い（険しい） |
| パララックス量 | 小さい | 大きい |

### 4. パララックス効果

マウスの X 位置に応じて各レイヤーの水平オフセットを計算します。手前の層ほどオフセット量が大きいため、実際に山を眺めて首を振るような視差が生まれます。

```js
const parallaxBase = (mouseX - W/2) / W;
const offsetX = parallaxBase * depth * maxAmount;
```

### 5. 夕焼けの空

背景は上から紫→橙→赤橙のグラデーション。太陽の周囲にはグローエフェクトを重ねて柔らかい光を表現しています。

## 試してみよう

- マウスをゆっくり左右に動かして、各層の動きの違いを観察してみましょう
- 何度かクリックして、同じアルゴリズムから多様な山脈が生まれるのを確認しましょう
- レイヤー数（`layers`）を増やすと、より奥行きのある風景になります
- ノイズのオクターブ数を減らすと、なだらかな丘陵地帯に変わります
