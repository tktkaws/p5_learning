## 地形ジェネレーション

**2D Perlin ノイズ**を使って高さマップを生成し、高さごとに色分けすることで島・山・海のある地形を手続き的に作り出します。クリックするたびに異なるシード値で新しい地形が生成されます。

### 操作方法

| 操作 | 動作 |
|------|------|
| クリック | 新しいシードで地形を再生成 |

## 仕組み

### 1. 2D ノイズで高さマップを生成

`noise(x, y)` は座標に対して滑らかに変化する 0〜1 の値を返します。これを各ピクセルの「高さ」として使います。

```js
let h = noise(x * SCALE, y * SCALE);
```

`SCALE` を小さくすると地形が大きく（なだらかに）、大きくすると地形が細かくなります。

### 2. 複数オクターブの重ね合わせ

1 層のノイズだけでは単調なので、周波数と振幅を変えた複数のノイズを重ねます。

```js
h = noise(nx, ny) * 1.0       // 大きな地形の起伏
  + noise(nx*2, ny*2) * 0.5   // 中くらいの凹凸
  + noise(nx*4, ny*4) * 0.25; // 細かいディテール
```

これは **フラクタルブラウン運動（fBm）** と呼ばれる手法で、自然な地形のスケール構造を模倣します。周波数を 2 倍にするごとに振幅を半分にするのがポイントです。

### 3. 島の形を作る

ノイズだけでは地形が画面端で不自然に途切れます。中心からの距離に応じて高さを下げることで、自然な島の形にします。

```js
const dist = sqrt(dx*dx + dy*dy); // 中心からの距離（0〜1）
h -= dist * 0.4;                  // 端ほど沈む
```

### 4. 高さに応じた色分け

高さの閾値で地形タイプを判定し、対応する色を割り当てます。

| 高さ範囲 | 地形 | 色 |
|----------|------|-----|
| 0.00 – 0.35 | 深海 | 濃い青 |
| 0.35 – 0.42 | 浅海 | 明るい青 |
| 0.42 – 0.45 | 砂浜 | ベージュ |
| 0.45 – 0.55 | 草地 | 明るい緑 |
| 0.55 – 0.65 | 森 | 濃い緑 |
| 0.65 – 0.78 | 山 | 茶色 |
| 0.78 – 0.88 | 高山 | 灰茶 |
| 0.88 – 1.00 | 雪 | 白 |

## loadPixels によるピクセル直接操作

全ピクセルを 1 つずつ `point()` で描くと遅いため、`loadPixels()` / `updatePixels()` で `pixels[]` 配列に直接書き込みます。400×400 = 160,000 ピクセルでも高速に処理できます。

## 試してみよう

- 何度かクリックして、同じアルゴリズムからどれだけ多様な地形が生まれるか観察してみましょう
- `SCALE` の値を変えると地形のスケールがどう変わるか試してみましょう
- 色の閾値を調整して、海面の高さや雪線を変えてみましょう
- オクターブ数を増やすと、より細かいディテールが加わります
