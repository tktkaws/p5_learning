## 棒グラフアニメーション

データの値が変わったとき、棒グラフがスムーズにアニメーションする仕組みを `p.lerp()` で実装します。データ可視化の基本であると同時に、イージング（補間）の考え方を学べるスケッチです。

### 操作方法

| 操作 | 動作 |
|------|------|
| クリック | 新しいランダムデータに切り替え |

## lerp（線形補間）とは

`lerp(a, b, t)` は、値 `a` から値 `b` へ `t`（0〜1）の割合で近づいた値を返す関数です。

```js
p.lerp(0, 100, 0.5)  // → 50（ちょうど中間）
p.lerp(0, 100, 0.25) // → 25（1/4 地点）
```

これを毎フレーム繰り返すと、**最初は大きく動き、徐々にゆっくりになる**アニメーションが自然に生まれます。

## アニメーションの仕組み

このスケッチでは「現在値」と「目標値」の 2 つの配列を持ちます。

```js
let currentValues = [];  // 今の高さ（描画に使う）
let targetValues = [];   // 目指す高さ（クリックで更新）
```

`draw()` の中で毎フレーム lerp を適用します。

```js
currentValues[i] = p.lerp(currentValues[i], targetValues[i], 0.08);
```

`0.08` は補間の速さです。毎フレーム「残りの差の 8%」だけ近づきます。

| フレーム | 差の残り | 移動量 |
|---------|---------|--------|
| 1 | 100% | 8.0 |
| 5 | 66% | 5.3 |
| 10 | 43% | 3.5 |
| 20 | 19% | 1.5 |
| 30 | 8% | 0.6 |

差が大きいほど速く、小さくなるほどゆっくり動くため、**ease-out**（減速）のような滑らかな動きになります。

## lerp の速度パラメータ

第 3 引数の値を変えると動きの性格が変わります。

| 値 | 動きの特徴 |
|----|-----------|
| `0.02` | ゆっくり、なめらか |
| `0.08` | 適度な速さ（このスケッチの値） |
| `0.2` | キビキビした動き |
| `0.5` | ほぼ即座に到達 |

## バーの色設計

カテゴリごとに色相を均等に配分しています。

```js
const hue = p.map(i, 0, BAR_COUNT, 200, 340);
```

色相 200（青）〜 340（ピンク）の範囲を使うことで、落ち着いた配色を実現しています。

## 試してみよう

- 何度もクリックして、アニメーションの「減速感」を観察してみましょう
- `LERP_SPEED` の値を `0.02` や `0.3` に変えて動きの違いを比較しましょう
- `BAR_COUNT` やカテゴリを増減して、グラフのレイアウトの変化を見てみましょう
- 色相の範囲を変えて、異なる配色を試しましょう
