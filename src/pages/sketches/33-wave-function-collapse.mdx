## Wave Function Collapse（WFC）

タイルの**制約伝搬**で模様を自動生成するアルゴリズムです。ゲームのマップ自動生成などに使われる手続き生成の基本手法で、量子力学の「波動関数の崩壊」から名前を借りています。

### 操作方法

| 操作 | 動作 |
|------|------|
| クリック | 新しいパターンを生成 |
| ↑ / ↓ キー | 崩壊速度を変更（1, 3, 10, 50 セル/フレーム） |
| R キー | リセット |

## アルゴリズムの仕組み

WFC は 3 つのステップを繰り返します。

### 1. 観測（Observe）

まだ確定していないセルの中から、**候補が最も少ないセル**（最小エントロピー）を選びます。候補が少ないセルを先に決めることで、矛盾が起きにくくなります。

```js
// 最小エントロピーのセルを探す
let minCount = Infinity;
for (let r = 0; r < ROWS; r++) {
  for (let c = 0; c < COLS; c++) {
    if (!cell.collapsed && cell.count < minCount) {
      minCount = cell.count;
      candidates.push({ r, c });
    }
  }
}
```

### 2. 崩壊（Collapse）

選んだセルの候補からランダムに 1 つを選んで確定させます。重み付きランダムを使い、タイルの出現頻度を調整しています。

```js
// 重み付きランダムでタイルを選択
let rand = random(totalWeight);
for (const tile of candidates) {
  rand -= tile.weight;
  if (rand <= 0) { chosen = tile; break; }
}
cell.tile = chosen;
cell.collapsed = true;
```

### 3. 伝搬（Propagate）

確定したセルの情報を隣接セルに伝え、**制約に合わないタイル候補を除去**します。除去が起きたセルからさらに隣へ…と連鎖的に広がります。

```js
// 隣接セルの候補を制約でフィルタリング
for (const neighbor of adjacentCells) {
  for (const tile of neighbor.options) {
    if (!isCompatible(current, tile, direction)) {
      neighbor.remove(tile); // 候補から除去
      stack.push(neighbor);  // さらに伝搬
    }
  }
}
```

## タイルと制約

このスケッチでは 12 種類のパイプタイルを使っています。各タイルの 4 辺（北・東・南・西）が「開（パイプあり）」か「閉（パイプなし）」かで定義されます。

| タイル | N | E | S | W | 形状 |
|--------|---|---|---|---|------|
| 空白 | 0 | 0 | 0 | 0 | （なし） |
| 横線 | 0 | 1 | 0 | 1 | ─ |
| 縦線 | 1 | 0 | 1 | 0 | │ |
| 角×4 | | | | | └ ┌ ┐ ┘ |
| T字×4 | | | | | ┬ ├ ┴ ┤ |
| 十字 | 1 | 1 | 1 | 1 | ┼ |

**制約ルール**: 隣接する 2 つのタイルは、共有する辺の値が一致しなければなりません。たとえば横線タイル（東=1）の右隣には、西=1 のタイルしか置けません。

```js
// 互換性チェック: タイルAの東辺 === タイルBの西辺
TILES[a].edges[EAST] === TILES[b].edges[WEST]
```

## 矛盾と解決

制約伝搬の結果、候補が 0 になるセルが発生することがあります。これが**矛盾**です。矛盾が起きた場合はリセットして最初からやり直します。

タイルの重みを調整することで矛盾の発生率を下げられます。このスケッチでは直線タイルを多め、T 字・十字を少なめに設定しています。

## 色について

タイルは**崩壊した順番**で色相が変化します。最初に確定したタイルは赤系、最後は青系になり、アルゴリズムがどの順番でセルを埋めていったかが視覚的に分かります。

## 試してみよう

- 速度を最低（1/f）にして、1 セルずつ崩壊する様子を観察してみましょう
- 崩壊の順番と色の関係から、最小エントロピー選択がどう働くか考えてみましょう
- 何度か生成して、矛盾がどのくらいの頻度で起きるか確認してみましょう
- 速度を最大にして、大量のパターンバリエーションを楽しみましょう
