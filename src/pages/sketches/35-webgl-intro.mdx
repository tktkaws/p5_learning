## WEBGL入門

p5.js の **WEBGL モード**を使って 3D 空間を描画します。5 種類の基本図形（プリミティブ）を配置し、ライティングとカメラ操作で 3D グラフィックスの基礎を学びます。

### 操作方法

| 操作 | 動作 |
|------|------|
| ドラッグ | カメラを回転 |
| スクロール | ズームイン / アウト |
| クリック | 自動回転の ON / OFF |
| R キー | リセット |

## WEBGL モードの始め方

`createCanvas()` の第 3 引数に `WEBGL` を指定するだけで 3D 描画が使えます。

```js
p.createCanvas(400, 400, p.WEBGL);
```

WEBGL モードでは**座標の原点がキャンバスの中央**になります。2D モード（左上が原点）とは異なるので注意が必要です。

## 5 つのプリミティブ

WEBGL モードで使える基本的な 3D 図形です。

| 関数 | 形状 | 引数 |
|------|------|------|
| `box(size)` | 立方体 | サイズ |
| `sphere(radius)` | 球 | 半径 |
| `torus(r, tubeR)` | トーラス（ドーナツ） | 半径, チューブ半径 |
| `cylinder(r, h)` | 円柱 | 半径, 高さ |
| `cone(r, h)` | 円錐 | 半径, 高さ |

```js
// 各図形を関数として定義
p.box(55);
p.sphere(30);
p.torus(22, 8);
p.cylinder(19, 44);
p.cone(22, 44);
```

## ライティング

3D で立体感を出すにはライト（光源）が不可欠です。

```js
// 環境光: 全体をぼんやり照らす
p.ambientLight(0, 0, 30);

// 指向性ライト: 方向を持つ平行光源（太陽光のイメージ）
p.directionalLight(0, 0, 80, 0.5, -1, -0.5);
//                  色(H,S,B)     方向(x, y, z)
```

| ライトの種類 | 特徴 |
|-------------|------|
| `ambientLight()` | 方向なし。影ができない均一な光 |
| `directionalLight()` | 平行光線。方向を指定して影を表現 |
| `pointLight()` | 点光源。位置から全方向に放射 |

## マテリアル

図形の表面の色や質感を決めるのがマテリアルです。

```js
// 環境光+指向性ライトに反応する色
p.ambientMaterial(350, 70, 90); // HSB で指定

// 自己発光（ライトの影響を受けない）
p.emissiveMaterial(50, 60, 95);
```

`ambientMaterial()` はライトとの相互作用で色が変化するため、ライトの色・方向によって見え方が変わります。

## カメラ操作

`orbitControl()` を `draw()` の中で呼ぶだけで、マウス操作によるカメラ回転とズームが有効になります。

```js
p.draw = () => {
  p.orbitControl(2, 2, 0.05);
  // 引数: X感度, Y感度, ズーム感度
};
```

## 座標変換は 2D と同じ

`translate()` と `rotate()` は 3D でもそのまま使えます。Y 軸が下向きなのは 2D と同じです。

```js
p.push();
p.translate(x, 0, z);  // 3D空間での移動
p.rotateY(angle);       // Y軸回りに回転
p.box(50);
p.pop();
```

## 試してみよう

- ドラッグでカメラを回転させ、3D 空間を色々な角度から眺めてみましょう
- スクロールでズームして、各図形の形状を近くで確認しましょう
- 自動回転を止めて、図形の自転だけを観察してみましょう
- 5 つのプリミティブの特徴（面の数、滑らかさ）の違いを比べてみましょう
