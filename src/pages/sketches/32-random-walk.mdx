## ランダムウォーク

毎フレームランダムな方向に歩く点の軌跡を描画します。乱数の分布を変えることで、まったく異なるパターンが生まれます。3 種類のウォークを切り替えて比較できます。

### 操作方法

| 操作 | 動作 |
|------|------|
| クリック | ウォークタイプを切り替え |
| R キー | 画面クリア＆再スタート |

## 3 つのランダムウォーク

### 1. 均一ランダム（格子ウォーク）

上下左右の 4 方向から等確率で 1 つ選び、固定ステップで移動します。最も古典的なランダムウォークです。

```js
const dir = floor(random(4));
if (dir === 0) x += step;
else if (dir === 1) x -= step;
else if (dir === 2) y += step;
else y -= step;
```

格子状の軌跡になり、出発点の周辺をうろうろする傾向があります。

### 2. 正規分布（ガウシアンウォーク）

`randomGaussian()` で移動量を決めます。小さな移動が多く、大きな移動はまれです。

```js
x += randomGaussian(0, 3); // 平均0、標準偏差3
y += randomGaussian(0, 3);
```

均一ランダムより滑らかで、自然界のブラウン運動（花粉の微小粒子の動き）に近い軌跡になります。

### 3. レヴィフライト

普段は小さく動き、**たまに大きくジャンプ**します。ステップサイズがべき乗分布に従います。

```js
const u = random(0.001, 1);
const stepSize = pow(u, -1/1.5) * 0.8; // べき乗分布
x += cos(angle) * stepSize;
y += sin(angle) * stepSize;
```

アホウドリの飛行パターンや人間の移動パターンがレヴィフライトに近いことが知られています。広い範囲を効率的に探索する戦略です。

## 分布の違いが軌跡に与える影響

| タイプ | ステップサイズ | 探索範囲 | 特徴 |
|--------|-------------|---------|------|
| 均一ランダム | 固定 | 狭い | 格子状、出発点付近に留まりやすい |
| 正規分布 | 小さめが多い | 中程度 | 滑らか、ブラウン運動的 |
| レヴィフライト | 大小混在 | 広い | 大ジャンプで遠くまで探索 |

## 拡散の速さ

均一ランダムと正規分布では、N ステップ後の出発点からの平均距離は **√N に比例**します。レヴィフライトではべき指数によっては距離の増加が √N より速く（超拡散）、より広い領域をカバーします。

## 試してみよう

- 3 タイプを切り替えて、同じステップ数での広がり方の違いを比べてみましょう
- レヴィフライトの大ジャンプがどのくらいの頻度で起きるか観察してみましょう
- ステップ数が増えると軌跡がどのように変化するか、しばらく放置して眺めてみましょう
