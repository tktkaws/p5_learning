## メタボール

複数の点が周囲に生む**影響値の等値面**を描画する技法です。ボール同士が近づくと有機的にくっつき、離れるとスムーズに分離します。1980 年代に CG 分野で考案され、溶岩ランプや液体のような表現に使われています。

### 操作方法

| 操作 | 動作 |
|------|------|
| マウス移動 | 1 つのボールがマウスに追従 |
| クリック | ボールを追加（最大 12 個） |
| D キー | ボールを 1 つ削除 |
| R キー | 初期状態にリセット |

## 影響関数

各メタボールは、周囲に距離に反じた**影響値**を放射します。ある点 (x, y) におけるボール i の影響値は：

```
f_i(x, y) = r_i² / ((x - cx_i)² + (y - cy_i)²)
```

ボールの中心に近いほど値が大きく、遠ざかると急速に減衰します。

```js
let sum = 0;
for (const ball of balls) {
  const dx = px - ball.x;
  const dy = py - ball.y;
  const distSq = dx * dx + dy * dy;
  sum += (ball.r * ball.r) / distSq;
}
```

全ボールの影響値を**合計**し、しきい値（ここでは 1.0）を超えた領域がメタボールの「内側」になります。

## なぜくっつくのか

2 つのボールが近づくと、中間地点での影響値が**両方のボールから加算**されます。合計がしきい値を超えると、その領域も「内側」として描画されるため、2 つのボールが滑らかに結合して見えます。

```
ボールA        ボールB
  ●─────────────●
      ↑ ここの影響値が
        A + B の合計で
        しきい値を超える
```

## 色のマッピング

影響値の大きさに応じて溶岩ランプ風のグラデーションを適用しています。

| 影響値 | 色 | 領域 |
|--------|-----|------|
| > 1.0 | 黄〜赤（暖色） | ボール内部 |
| 0.5 〜 1.0 | 紫〜赤（遷移） | 表面付近 |
| 0.2 〜 0.5 | 青〜紫（寒色） | 外縁のグロー |
| < 0.2 | ほぼ黒 | 背景 |

## パフォーマンスの工夫

400×400 のキャンバスで毎ピクセル計算すると 160,000 回 × ボール数の計算が毎フレーム必要です。このスケッチでは**解像度を 1/4**（100×100）で計算し、拡大表示することで処理を軽くしています。

```js
const RES = 4;
const GW = W / RES; // 100
const GH = H / RES; // 100
// 100×100 = 10,000回の計算で済む
```

粗さが逆にレトロな雰囲気を出す効果もあります。

## 試してみよう

- マウスを動かして、ボール同士がくっつく瞬間を観察してみましょう
- クリックでボールを追加すると、複数のボールが合流する様子が見られます
- D キーでボールを減らして、2 個だけの状態でくっつき・分離を観察してみましょう
- ボールが多いほど全体が溶け合い、少ないと個別の形が見えます
