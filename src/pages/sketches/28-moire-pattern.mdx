## モアレパターン

**モアレパターン（Moiré pattern）**は、2つの規則的な縞模様を重ね合わせたときに生じる干渉縞です。テレビ画面を撮影したときに見える波模様や、2枚のフェンスが重なって見える模様もモアレの一種です。

### 操作方法

| 操作 | 動作 |
|------|------|
| マウス左右 | 2つ目の縞の回転角度を変更（0° 〜 180°） |
| マウス上下 | 2つ目の縞の間隔を変更（密 〜 粗） |

角度や間隔をわずかに変えるだけで、干渉縞の模様が大きく変化します。

## 仕組み

### 2つの縞パターン

このスケッチでは 2 種類の白黒の縞模様を使います。

- **パターン 1**（固定）: 垂直な等間隔の縞
- **パターン 2**（マウス操作）: 回転と間隔が変化する縞

### XOR による干渉

各ピクセルで 2 つのパターンの値を **XOR（排他的論理和）**で合成します。

```
パターン1: ■□■□■□■□
パターン2: ■■□□■■□□
XOR結果:   □■■□□■■□
```

- 両方「黒」または両方「白」→ 黒
- 片方だけ「黒」→ 白

この単純な演算だけで、複雑な干渉縞が自然に出現します。

### 縞の判定

あるピクセルが「黒」か「白」かは、座標を縞の方向に射影して判定します。

```js
// 角度 θ の縞パターンに対して
const projected = dx * cos(θ) + dy * sin(θ);
const stripe = Math.floor(projected / spacing) % 2;
```

`projected` は座標を縞に垂直な軸に射影した値です。これを間隔 `spacing` で割り、偶数番目か奇数番目かで白黒を決めます。

## なぜ干渉縞が見えるのか

2 つの縞の間隔や角度がわずかに違うとき、「同位相の領域」と「逆位相の領域」が空間的に大きな周期で繰り返します。これが人間の目にはうねるような太い帯——モアレ縞として知覚されます。

間隔 `s1` と `s2` の 2 つの縞を重ねたとき、モアレ縞の間隔 `M` は近似的に次の式で表されます：

```
M = (s1 × s2) / |s1 - s2|
```

`s1` と `s2` が近いほど `M` は大きくなり、ゆったりとしたうねりが現れます。

## 試してみよう

- マウスをゆっくり左右に動かして、角度の微小な変化でモアレ縞がどう変わるか観察してみましょう
- マウスを上下に動かし、間隔が近いとき（下側）にモアレが顕著になることを確認しましょう
- 角度 0° 付近と 90° 付近でモアレの出方がどう違うか比べてみましょう
