## パーティクル銀河

4000 個のパーティクルを 3D 空間で螺旋状に配置し、回転する銀河を表現します。WEBGL の `point()` を使って大量の粒子を効率的に描画します。

### 操作方法

| 操作 | 動作 |
|------|------|
| ドラッグ | カメラを回転 |
| スクロール | ズームイン / アウト |
| クリック | 自動回転 ON / OFF |

## 銀河の構造

実際の渦巻銀河と同様に、2 つの要素で構成しています。

### 中央バルジ

銀河の中心にある球状の密集領域です。ガウス分布（正規分布）で粒子を配置し、中心ほど密度が高くなるようにしています。

```js
const r = gaussianRandom() * 30;
const theta = p.random(p.TWO_PI);
const phi = p.random(p.PI);

const x = r * p.sin(phi) * p.cos(theta);
const y = (r * p.cos(phi)) * 0.4; // 縦方向を圧縮
const z = r * p.sin(phi) * p.sin(theta);
```

Y 軸方向を `0.4` 倍に圧縮することで、球ではなく扁平な楕円体にしています。

### 渦巻き腕

2 本の腕を対数螺旋に沿って配置します。各パーティクルは腕の中心線からランダムに散らばります。

```js
const t = p.random(0.1, 1.0);       // 中心からの距離パラメータ
const radius = t * 150;
const spiralAngle = armOffset + t * 3.5; // 距離に応じて巻く
const spread = t * 20;              // 外側ほど散らばる
```

- `t * 3.5` の係数が腕の「巻き具合」を決めます。大きいほどきつく巻きます
- `spread` が外側ほど大きくなることで、腕が外側で広がる自然な形になります

## ガウス分布による配置

`Math.random()` の一様分布ではなく、Box-Muller 変換で正規分布の乱数を生成しています。

```js
function gaussianRandom() {
  let u = 0, v = 0;
  while (u === 0) u = p.random();
  while (v === 0) v = p.random();
  return Math.sqrt(-2.0 * Math.log(u)) * Math.cos(p.TWO_PI * v);
}
```

正規分布を使うことで、中心や腕の中心線付近に粒子が集中し、自然な密度勾配が生まれます。

## 色の設計

実際の銀河の色分布を参考にしています。

| 位置 | 色 | 理由 |
|------|-----|------|
| 中心（バルジ） | 黄〜白 | 古い恒星が密集、温度が高い |
| 腕の内側 | 暖色（オレンジ〜黄） | 赤色巨星が多い |
| 腕の外側 | 青白い | 若い高温の恒星が多い |

```js
const hue = p.map(t, 0.1, 1.0, 35, 220); // 内側:暖色 → 外側:青
const bri = p.map(t, 0.1, 1.0, 95, 65);  // 内側:明るい → 外側:やや暗い
```

## パフォーマンス

4000 個の粒子を毎フレーム描画するため、`p.point()` で 1 ピクセルずつ打つ方式を採用しています。`sphere()` を 4000 回呼ぶよりもはるかに軽量です。`strokeWeight` で粒子のサイズに変化を持たせ、単調にならないようにしています。

## 試してみよう

- ドラッグで銀河を横から見ると、薄い円盤構造が確認できます
- ズームインして中央バルジの密度を観察しましょう
- `NUM_ARMS` を 3 や 4 に変えると腕の数が変わります
- `t * 3.5` の係数を変えると螺旋の巻き具合が変わります
